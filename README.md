# Automated Pet Feeder Project

## 📌 Overview
This project is part of the *Introduction to Information Technology (4478/8936)* course at the University of Canberra.  
The aim is to design and simulate the logic and behaviour of a **low-cost automated pet feeder system** using the **Problem-Solving Process**.

The feeder is intended for use in an animal shelter and must:
- Dispense food for cats and dogs at scheduled times.
- Monitor whether food has been consumed.
- Alert staff if there are issues (e.g., no food dispensed, pet not eating, food bin empty).

## 🔎 Problem-Solving Process

1. **Analysis** – Defined problem, features, assumptions, inputs, and outputs.  
2. **Data Description** – Created a table of inputs/outputs with sample values and constraints.  
3. **Algorithm Design** – Designed a flowchart (Draw.io) showing the feeder’s decision-making process.  
4. **Implementation (Word Code)** – Translated the flowchart into structured pseudo-code.  
5. **Testing** – Ran scenarios (pet eats, pet doesn’t eat, food bin empty) and suggested refinements.

---

## 📊 Key Features of the System
- **Scheduled Feeding:** Dispenses food at 8:00 AM and 6:00 PM.  
- **Sensors:** Detects food level in container and bowl weight.  
- **Alerts:** Sends notifications if the pet does not eat or if the food bin is empty.  
- **Low-Cost Components:** Can be implemented using Arduino or Raspberry Pi with servo motors and load sensors.
