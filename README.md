# Automated Pet Feeder Project

## 📌 Overview
This project is part of the *Introduction to Information Technology (4478/8936)* course at the University of Canberra.  
The aim is to design and simulate the logic and behaviour of a **low-cost automated pet feeder system** using the **Problem-Solving Process**.

The feeder is intended for use in an animal shelter and must:
- Dispense food for cats and dogs at scheduled times.
- Monitor whether food has been consumed.
- Alert staff if there are issues (e.g., no food dispensed, pet not eating, food bin empty).
